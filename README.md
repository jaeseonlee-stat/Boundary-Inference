# Statistical inference for boundary constrained parameters

Code to reproduce results from the paper "Statistical inference for boundary constrained parameters" by Lee, Bhattacharya, and Subba Rao (2026+).

## File description

### Simul: folder for simulation code
- `Algorithm_1.R`: code for running simulation with Algorithm 1
- `Algorithm_2.R`: code for running simulation with Algorithm 2

### others: folder for reproducing other results
- `Mixture_Prob_Verification.R`: code for numerical verification of mixture probability for p=3 (illustrated in Table 1)
- `Finite_sample_dist_p2.R`: code for reproducing Examples 1-3 and figures (Figures 1-4). The detailed settings are described in Section G.2 in the Supplementary Material.
